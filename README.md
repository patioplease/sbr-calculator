# SBR Aeration Calculator

Installable, offline web app for GRAF One2Clean SBR aeration cycle, sugar (carbon) dosing and sludge management.
Formulas are a direct port of `Final_Aeration_Cycle_Calulator_CGPT_X_Gemini_v3.xlsx`, verified cell-for-cell against the workbook.

Open the GitHub Pages link in Chrome on Android and tap **Install** (or menu → Add to Home screen).
