# SBR Aeration Calculator

Installable, offline web app for GRAF One2Clean SBR aeration cycle, sodium acetate (carbon) dosing and sludge management.
Formulas are a direct port of `Final Aeration Cycle Calulator (CGPT X Gemini) v4.xlsx` (sodium acetate, first-visit mode), checked cell-for-cell against the workbook.

The acetate dose is given in litres of stock (default 100 g/L sodium acetate trihydrate). First-visit mode schedules no top-up dose.

Open the GitHub Pages link in Chrome on Android and tap **Install** (or menu → Add to Home screen).
